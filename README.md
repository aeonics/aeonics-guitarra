# AEONICS OPEN-Music
## RECURSOS MUSICALES: GUITARRA

Aprender guitarra no debería significar buscar cientos de vídeos
sin saber por dónde empezar.

> **Estado:** investigación / construcción del catálogo

## Objetivo

Aeonics Open es un proyecto abierto para organizar recursos de
aprendizaje de guitarra y desarrollar, a partir de ellos, una ruta
de aprendizaje musical estructurada.

El proyecto no pretende sustituir a profesores ni presentar una
única metodología como universal.

## Principios

- Priorizar recursos gratuitos y accesibles.
- Favorecer fuentes confiables y pedagógicamente estructuradas.
- Separar evidencia científica, experiencia profesional y opinión.
- Indicar qué habilidad desarrolla cada recurso.
- Evitar colecciones de ejercicios sin propósito.
- Explicitar nivel, duración, objetivo y prerrequisitos.
- Mantener enlaces directos a las fuentes originales.
- Respetar las licencias de cada recurso.

## Áreas curriculares

1. Técnica
2. Ritmo
3. Escalas
4. Diapasón
5. Acordes
6. Armonía
7. Oído
8. Transcripción
9. Repertorio
10. Improvisación
11. Lectura
12. Sonido y articulación
13. Interacción con otros músicos
14. Creación
15. Performance

## Estructura

- `curriculum/` — mapa curricular y rutas.
- `resources/` — catálogo de recursos.
- `research/` — metodología y evidencia.
- `docs/` — contenido para GitHub Pages.
- `CONTRIBUTING.md` — criterios para aportar recursos.

## Estado

La primera fase consiste en investigar, evaluar y catalogar recursos
antes de construir la plataforma web.
